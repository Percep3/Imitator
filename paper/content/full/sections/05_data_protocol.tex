\section{Data and Protocol}

LSA64 has 3,200 videos of 64 Argentinian Sign Language signs, performed five times
by ten subjects \citep{ronchetti2016lsa64}.  We normalize 111 upper-body, hand,
and facial 2D keypoints per frame.  Each example concatenates two to eight clips
with optional neutral gaps; its target concatenates the \Gemma{} tokenizations of
their Spanish labels.  For each example, clip IDs are drawn at random with
replacement from the pool assigned to that split, so a source clip may recur
across examples or more than once in one example.  The pools are partitioned by
signer, so no source clip is shared across train, validation, and test within a
fold.  Random order prevents a linguistic next-sign prior but contains neither
syntax nor coarticulation.  The task is controlled token transcription, not
continuous SLT.

Each LOSO fold excludes an outer-test signer, uses another for inner validation,
and trains on the rest.  Folds 1--6 are development, 7--8 prospective confirmation,
and 9--10 reserved.  \ImitatorEOne{} uses seed 23, 2,048 training examples per
epoch, 512 fixed inner-validation examples, 30 epochs, and 896 outer examples.
Checkpoint selection uses inner-validation edit similarity, then strict accuracy;
outer results select nothing.

We train with AdamW (weight decay $10^{-4}$), a physical batch size of two, and
two gradient-accumulation steps (effective batch size four).  The decoder uses a
learning rate of $3\times10^{-4}$.  After five decoder-only epochs, we unfreeze
the temporal convolutions and visual Transformer at $3\times10^{-5}$; the ST-GCN
and spatial projection remain frozen.  For each isolated clip, we retain 111 of
the original 133 upper-body, face, and hand landmarks, take absolute coordinates,
exclude near-zero invalid landmarks when computing per-axis extrema, and min--max
scale valid coordinates within that clip while preserving invalid markers.
Neutral gaps are inserted after normalization.

CIF (Continuous Integrate-and-Fire \citep{dong2020cif}) is a non-autoregressive
alignment mechanism that pools frame features into one embedding per detected
segment via a learned, accumulating firing weight, then classifies each segment
independently.  Our comparator reuses the same ST-GCN visual-encoder design as
our earlier published \system{} \citep{velasquez2026imitator}, paired with a
non-autoregressive segment-classification head that we developed and evaluated
earlier in this study, before adopting the autoregressive design used by
\ImitatorEOne{}.  Because CIF's raw fired-segment count does not exactly match
the target token count, we fit an affine length calibration
($\mathrm{count}=a\cdot\mathrm{raw}+b$) on inner-validation data only and freeze
it before outer-test evaluation; we call this frozen, calibrated model
historical affine CIF.  Unlike \ImitatorEOne{}'s autoregressive causal decoder,
CIF classifies all segments in parallel and needs no learned stopping token; its
frozen encoder weights also initialize \ImitatorEOne{}'s visual encoder
(Section~4).

The preregistration requires, on each confirmation fold: more strict-accuracy wins
than losses against historical affine CIF with sign-test $p<.01$ (H1); strict
accuracy $\geq11.9\%$ (H2); and pair order $\geq.90$ plus permutation edit drop
$\geq.15$ (H3).
